Проектируемый объект — Административно-деловой комплекс — массивный объемно-планировочный объект, который состоит из L-образной башни и ступенчатых блоков со скругленными углами, объединенных вместе. Террасы, образуемые сдвижкой объемов, запроектированы для использования посетителями и работниками офисов.

Подземная часть представляет собой двухуровневую подземную автостоянку.

Кровля подземной автостоянки является внутренним благоустроенным пешеходным двором, организованным по принципу «без машин» с доступом для пожарной и другой специальной техники. По периметру наземной части объекта предусмотрен круговой объезд для пожарной техники, для доступа легкового автотранспорта к подъездам корпусов, для другой специальной техники.

В составе комплекса предусмотрены:

− помещения организации торговли;

− помещения организации общественного питания;

− офисы;

− санитарно-бытовые помещения работников и посетителей;

− помещения для размещения инженерно-технического оборудования здания;

− административно-бытовые помещения службы эксплуатации и управления зданием.
